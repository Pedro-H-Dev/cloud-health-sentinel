# Cloud & GitOps Health Sentinel 🛡️

Ferramenta leve de automação em Python para auditoria e monitoramento de saúde de repositórios via GitHub API, totalmente conteinerizada com Docker.

## 🚀 Tecnologias Utilizadas
- **Python 3.11** (Lógica de automação e consumo de API)
- **GitHub API** (Extração de métricas de repositórios)
- **Docker** (Isolamento e portabilidade de ambiente)
- **Git** (Controle de versão)

## 🎯 Objetivo do Projeto
Demonstrar competência em automação de infraestrutura, integração com APIs REST e conteinerização de aplicações para cenários de DevOps e Cloud.

## 🛠️ Como Executar o Projeto

### Pré-requisitos
- Ter o [Docker](https://www.docker.com/) instalado e rodando na sua máquina.

### Executando via Docker
1. Clone este repositório:
   ```bash
   git clone [https://github.com/Pedro-H-Dev/cloud-health-sentinel.git](https://github.com/Pedro-H-Dev/cloud-health-sentinel.git)
   cd cloud-health-sentinel
   ```
